# Power BI Report Screenshots Directory
## Project: Retail Sales & Customer Analytics (Aura Retail Group)

This directory is designated for high-resolution PNG exports and screenshots of the 6 Power BI report pages.

### Required File Inventory:
1. `01_executive_overview.png` — Page 1: Executive Overview (KPI cards, Monthly Revenue/Profit trend, Regional donut, Top 10 products, Category mix).
2. `02_sales_trends.png` — Page 2: Sales & Trends (Longitudinal revenue vs. profit combo, Category stacked columns, Regional areas, P&L monthly matrix).
3. `03_product_performance.png` — Page 3: Product Performance (Top 10 / Bottom 10 SKUs, Category treemap, Strategic Margin vs. Volume Scatter Chart).
4. `04_customer_analytics.png` — Page 4: Customer Analytics (Retention KPIs, Repeat vs. One-time donut, Spend distribution, VIP LTV Leaderboard).
5. `05_store_regional_performance.png` — Page 5: Store & Regional Performance (Territory bars, Store benchmarking matrix, Geographic map, Top/Bottom stores).
6. `06_profitability_opportunities.png` — Page 6: Profitability & Opportunities (Financial waterfall, Discount band elasticity, Portfolio pricing matrix, Actionable insights).

### Export Instructions:
1. Open the report in **Power BI Desktop**.
2. Set display to **100% (Fit to Page)**.
3. For each page, capture the full 16:9 canvas using the Windows Snipping Tool (`Win + Shift + S`) or `File` -> `Export` -> `Export to PDF` (and convert pages to PNG).
4. Save the files into this directory using the exact names listed above.
